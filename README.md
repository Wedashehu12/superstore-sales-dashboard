# superstore-sales-dashboard
Power BI sales dashboard project analyzing retail sales trends, categories, and regional performance.

## Project Overview
This project is a Power BI dashboard created using a retail sales dataset. The dashboard provides insights into sales performance, customer segments, regional trends, and product categories.

## Tools Used
- Power BI
- Excel / CSV Dataset
- Data Visualization
- Business Analytics

## Dashboard Features
- Total Sales KPI
- Sales by Category
- Sales by Region
- Sales Trends Over Time
- Interactive Region Filter

## Key Insights
- Technology category generated the highest sales
- West region had the strongest sales performance
- Sales increased significantly over time
